# Sucio Records

Website for [Sucio Records](https://suciorecords.bandcamp.com), a lofi and abstract hip-hop label from Cali, Colombia.

A single static page: `index.html` plus `assets/`. No build step. Open `index.html` in a browser to preview.

- Design rules, colors and type: [DESIGN.md](DESIGN.md). Shared styles: `assets/brand.css`.
- Data still to confirm (WhatsApp and Nequi numbers, prices, links) is outlined in red with the `.ph` class. Remove the class once the real value is in.
- Deployed on Vercel. Every push to `main` goes to production.
